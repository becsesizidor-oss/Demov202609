# FTS Demo – Functional Training System

Az FTS egy Windows rendszerre készült, helyben futó edzéstervező és klienskezelő alkalmazás bemutatóverziója.

A Demo verzió célja az FTS felületének és legfontosabb funkcióinak kipróbálása. Az alkalmazás használatához nem szükséges Python, Visual Studio Code vagy más fejlesztői környezet.

## A ZIP-fájl tartalma

A kiadásnál letölthető `FTS Demo.zip` kibontása után az alábbi elemek találhatók:

* `FTS.exe` – az alkalmazás indítófájlja;
* `_internal` – az FTS működéséhez szükséges Python-környezet, programkönyvtárak, sablonok, képek és kezdő adatbázis;
* `FTS_Projekt_bemutato.pptx` – az FTS bemutató prezentációja;
* `FTS Muszaki_specifikacio 2026.09.12.pdf` – a projekt műszaki dokumentációja.

## Letöltés és indítás

1. Nyissa meg a GitHub-oldal **Releases** részét.
2. Válassza ki a `Demov202609` kiadást.
3. Töltse le az `FTS Demo.zip` fájlt.
4. Bontsa ki a teljes ZIP-fájlt egy külön mappába.
5. Nyissa meg a kibontott `FTS` mappát.
6. Indítsa el az `FTS.exe` alkalmazást.
7. Az FTS automatikusan megnyílik az alapértelmezett böngészőben.
8. Belépési adatok: Felhasználónév "FTS" jelszó: "Projekt01"
## Fontos

Az `FTS.exe` és az `_internal` mappa mindig maradjon egymás mellett. Az EXE-fájlt ne helyezze át önmagában másik mappába, mert az alkalmazásnak szüksége van az `_internal` tartalmára.

A Windows első indításkor ismeretlen alkalmazásra vonatkozó SmartScreen-figyelmeztetést jeleníthet meg. Ilyenkor válassza a **További információ**, majd a **Futtatás mindenképpen** lehetőséget, ha a fájlt erről a hivatalos GitHub-oldalról töltötte le.

## Rendszerkövetelmény

* 64 bites Windows 10 vagy Windows 11;
* alapértelmezett webböngésző;
* szabad 5000-es helyi hálózati port;
* internetkapcsolat csak a letöltéshez szükséges.

## Demo-verzió

Ez egy prezentációs célú, korlátozott bemutatóverzió. A választható gyakorlatok száma eszközönként és izomcsoportonként legfeljebb három. A teljes fejlesztési forráskód nem része a letölthető csomagnak.
